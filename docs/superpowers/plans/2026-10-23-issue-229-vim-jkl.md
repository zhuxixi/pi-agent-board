# Vim-style j/k/l Board Keys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bind `j`/`k` navigation and `l` attach in the board's list/select/peek/evidence modes so vim users' muscle memory works, without touching text-input modes or the `h` = Hold contract (issue #229).

**Architecture:** Pure additive key branches in the five per-mode handlers of `src/ui/dashboard.ts`, reusing the exact code paths of the arrow keys (`moveSelection`, `peekStep`, `attachSelected`, `attachPeek`); copy sync in the `?` help overlay, the NORMAL/SELECT hint lines, and the four README view tables. Behavior is verified by a `test-support` probe driving the public `handleInput()` with fake service/done injection.

**Tech Stack:** TypeScript (runtime), `node --test` + `--experimental-transform-types` probes (test).

**Spec:** `docs/superpowers/specs/2026-10-23-issue-229-vim-jkl-design.md` (acceptance IDs A1–A9, U1–U2 referenced below)

## Global Constraints

- Tabs for indentation; English comments and commit messages (AGENTS.md).
- Tests use `node:test` with `assert/strict`; probes run via `node --experimental-transform-types` and live in `test-support/` (excluded from tsconfig).

- `j`/`k` inherit **wrap-around** semantics via `moveSelection`/`peekStep` — do NOT implement clamp (spec D2).
- `h` = Hold (PR #151 contract), dispatch/filter/rename/reply stay literal — off-limits (spec D4/D6).
- Worktree discipline: all edits under `/home/elling/work/git-repo/pi-agent-board/.pi/worktrees/issue-229-vim-jkl-board-list` (= `$WT`), git via `git -C $WT`.

## Review Focus

1. **Uppercase `J`/`K`/`L` stay unbound** — list mode still shows the printable fallback toast for them. Expected: unchanged current behavior, pinned by a probe assertion (Task 1, Step 1).
2. **`l` on a busy row** (`hostActive=false && agentBusy=true`) must take the same `confirm-stop-first` branch as `→`, not attach directly. Pinned by the `busyL` probe segment (Task 1, Step 1).
3. **Help rows got longer** — at 80 cols `renderCenteredBox` clips (existing fallback, `dashboard.ts:1846`); full wording must be visible at 120 cols. Pinned by the render assertions (Task 2, Step 1).
4. **`j`/`k` in select mode trigger `prewarmScheduler.schedule()`** — inherited `moveSelection` side effect, select is in the `prewarmSelected` allow-list, no behavior change. No test; reviewers confirm no new coupling.
5. **Bracketed paste containing `j`/`k`/`l` must not move the selection** (multi-byte paste string never equals a single-byte key). Pinned by the paste segment (Task 1, Step 1).

```js
import assert from "node:assert/strict";
import { execFileSync } from "node:child_process";
import { fileURLToPath } from "node:url";
import { join } from "node:path";
import test from "node:test";

const ROOT_DIR = fileURLToPath(new URL("../", import.meta.url));
const PROBE = join(ROOT_DIR, "test-support", "vim-keys-wrap.ts");

test("vim j/k/l bindings mirror the arrow keys across board modes (issue #229)", () => {
	const out = JSON.parse(execFileSync(process.execPath, ["--experimental-transform-types", PROBE], { encoding: "utf8", timeout: 30_000 }));
	const { ids } = out;
	assert.equal(ids.length, 3, "probe must see 3 rows");
	// A1: list j/k wrap like the arrows; j/k never pop the INSERT toast.
	assert.deepEqual(out.list, [ids[1], ids[2], ids[0], ids[2], ids[2]], "j down x2, wrap; k wrap; paste no-move");
	assert.deepEqual(out.notices, [true, true], "j: no INSERT toast; J: keeps the printable fallback");
	// A2: select mode j/k move (wrap).
	assert.deepEqual(out.select, [ids[1], ids[0], ids[2]]);
	// A3: peek j/k step (wrap).
	assert.deepEqual(out.peek, [ids[1], ids[0], ids[2]]);
	// A4: l attaches in list / peek / evidence.
	assert.deepEqual(out.attach.map((r) => [r.action, r.viewId, r.stopFirst]), [
		["attach", ids[0], false],
		["attach", ids[1], false],
		["attach", ids[2], false],
	]);
	// A9: l stays unbound in select / session.
	assert.deepEqual(out.negative, [["select-l", "select", 0], ["session-l", "session", 0]]);
	// A6: session / evidence j/k still scroll.
	assert.deepEqual(out.scroll, [1, 0, 1, 0]);
	// A5: text modes keep j/k/l literal.
	for (const m of ["dispatch", "filter", "rename", "reply"]) assert.equal(out.text[m], "jkl", m);
	// RF2: busy row + l -> confirm branch, no direct attach.
	assert.equal(out.busyL.mode, "confirm");
	assert.equal(out.busyL.done, 0);
	assert.match(out.busyL.prompt, /Interrupt and attach/);
});
```
